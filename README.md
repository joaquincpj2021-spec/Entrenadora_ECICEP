# Entrenamiento clínico ECICEP + IA gratis con Gemini

Esta versión conserva la app y cambia el backend IA desde OpenAI API a Gemini API.

## Variables de entorno en Vercel

Crear estas variables:

- GEMINI_API_KEY: clave creada en Google AI Studio.
- GEMINI_MODEL: gemini-1.5-flash

No necesitas OPENAI_API_KEY ni OPENAI_MODEL para esta versión.

## Seguridad

No ingresar RUT, nombres, direcciones, teléfonos ni datos identificatorios.
La IA es apoyo educativo para entrenamiento clínico, no reemplaza juicio clínico.
